# Open Spotlight Bar Roadmap

## Phase 1

- stabilize launcher shell and platform hotkey behavior
- improve platform app discovery quality
- polish settings persistence and index controls

## Phase 2

- clipboard provider and action set
- snippets provider and expansion flow
- smarter file root selection and incremental indexing

## Phase 3

- plugin host runtime and permission prompts
- official plugins beyond calculator, GitHub, and shell
- richer provider and action extension APIs

## Phase 4

- packaging, signing, notarization, and update channels
- telemetry-free diagnostics for user troubleshooting
- beta release process per platform
